## 📌 核心痛点与研究动机

decoder-only 模型的跨语言分词长度和位置不同，逐 token 对齐没有天然对应。作者选择专家利用分布作为序列级对齐对象，让路由监督影响前序表征；关键不是简单增加平行数据，而是在相同继续预训练数据上隔离辅助损失的作用。

## ⚙️ 核心机制与数学公式推导

原文 §3.2 对 **top-k 后归一化、其他专家置零** 的路由权重做均值池化。英语序列作为参照，不接收梯度；目标语言同时优化语言模型与对齐目标。

$$
\bar{\mathbf p}_{\ell}^{\,x}
=\frac{1}{T_x}\sum_{t=1}^{T_x}G(\mathbf z_{\ell,t}^{\,x}),
\qquad
\mathcal L_{\mathrm{XLR}}
=\frac{1}{|\mathcal M|}\sum_{\ell\in\mathcal M}
D_{\mathrm{KL}}\!\left(
\operatorname{sg}(\bar{\mathbf p}_{\ell}^{\,\mathrm{eng}})
\middle\|\bar{\mathbf p}_{\ell}^{\,\mathrm{tgt}}\right).
$$

$$
\mathcal L=\mathcal L_{\mathrm{LM}}+\alpha\mathcal L_{\mathrm{XLR}}.
$$

符号：$G$ 是稀疏门控，$T_x$ 为序列 token 数，$\mathcal M$ 为预先选定的中层，$\operatorname{sg}$ 明示原文的停止梯度。中层依据路由分歧曲线选择，不强制所有层同质化。工程实现将双语序列打包，维持注意力边界，并让英语 token 在最后一个对齐层后退出，减少额外计算。

def xlr_loss(english_routes, target_routes, middle_layers):
    terms = []
    for layer in middle_layers:
        # 输入为 top-k 后权重；必须排除 padding / packing 边界
        p = masked_mean(english_routes[layer]).detach()
        q = masked_mean(target_routes[layer])
        terms.append(stable_kl(p, q))
    return mean(terms)

## 💡 与我们研究的闭环关联

主归档对应本仓库 MoE Model / Routing 文献方向。与 Transformer-Geometry 的关联是可观测表征变化，而不是已证明的几何约束机制；与专家压缩的关系仍是假设，路由一致性提高不代表专家可删除。

## 🛠️ 工程启发与落地边界

先固定门控定义、有效 token 与 KL 数值稳定性，再复现 packed forward；对齐层选择和辅助损失尺度独立做消融。长期预训练、无平行数据语言及更大架构的有效性不能从短程 CPT 外推。
