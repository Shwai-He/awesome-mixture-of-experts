# Cross-Lingual Alignment for Decoder-Only Models using MoE Routers

归档日期：2026-10-03（America/New_York）；原始精读截止：2026-10-03 20:40 EDT。本次归档再次核对 arXiv 摘要页的题名与编号。以下为预印本作者报告与研究建议，未独立复现，代码开放状态未经独立确认。

## 项目关联与证据边界

主归档于本仓库的 MoE Model / Routing 文献方向：该文研究路由输出如何塑造跨语言表征，不是专家剪枝算法；可作为专家专门化与负载分析的补充。

## 论文笔记

[论文](https://arxiv.org/abs/2610.01921) · [原文](https://arxiv.org/html/2610.01921v1) · [PDF](https://arxiv.org/pdf/2610.01921)；首次提交：2026-10-01。

1. **瓶颈**：跨语言 tokenization 不一致，使 decoder-only 的 token 表征难以直接对齐。
2. **方法**：将各 token 路由概率均值池化，针对选定中层最小化英语与目标语言分布的 KL；原文目标为 `L = L_LM + α L_XLR`，英语支路不回传梯度。
3. **实验与边界**：四个 MoE、七种语言的受控继续预训练支持路由/隐状态对齐及下游改善；短程训练与平行文本依赖限制外推。不是剪枝或部署加速结论。
4. **研究关联／最小实验（建议）**：对 Transformer 几何与容量感知路由，比较跨语言路由 KL、隐状态相似度与专家负载；固定数据和激活预算，测试“更对齐”是否仍保留语言特异性。
5. **工程启发**：区分 top-k 后稀疏权重与原始 logits；保持 pooling 与 padding 口径一致，先测表征，再讨论裁剪专家。
